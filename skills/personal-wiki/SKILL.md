# personal-wiki

オーナー一人の Markdown wiki。MCP サーバー `personal-wiki` の tool で読み書きする。

## いつ読むか

- 作業を始めるとき、主題の語で `search` し、関連するノートがあれば `read_page` で読んでから進める。
- ノートの中の `[[title]]` は別のノートへのリンク。必要なら `read_page` で title を渡して辿る。
- あるノートを参照しているノートを探すときは `list_backlinks`、最近の動きを知りたいときは `list_recent` を使う。
- `search` は 3 文字以上なら全文検索、2 文字以下なら部分一致になる。短い語で見つからなければ語を足す。

## どこに何を書くか

- 新しく作る前に `search` で同じ主題のノートを探す。あれば新しく作らず、そのノートに追記するか更新する。
- title は wiki 全体で一意。主題が後から見て分かる具体的な名前にする。
- 作業中のメモ、調べた結果、決めたことは `append_to_page` で末尾に足す。本文全体を書き換えるのは、構成を直すときだけにする。

## 書いてはいけないもの

- パスワード、API キー、トークン、個人情報などの秘密を書かない。
- 作るノートは draft になる。draft は公開ページの一覧には出ないが、URL を知っていれば誰でも読める。秘密を置く場所にはならない。

## 公開範囲

- ノートは draft で作られる。公開（public にする）のはオーナーがブラウザで行う。tool から公開範囲は変えられないので、公開を頼まれたらオーナーに伝える。
- frontmatter に公開範囲を書いても反映されない。

## 更新の手順

1. `read_page` で本文と version を取る。
2. `update_page` に取った version と新しい本文を渡す。
3. version が合わない（他で更新された）と失敗し、現在の本文と version が返る。返った本文を読み直し、変更を載せ直してから再度 `update_page` する。上書きで押し切らない。

追記だけなら version は要らない。`append_to_page` を使う。他の保存と競合し続けて失敗したときは、同じ追記をそのまま送り直してよい。
